# موقع يحيى الجزري

موقع ثابت (HTML/CSS/JS) جاهز لـ GitHub Pages، عربي (RTL)، بلا أي أدوات بناء.

## البنية

```
index.html     هيكل الصفحة والنصوص
style.css      التصميم (الألوان في أعلى الملف داخل :root)
script.js      بناء القصص والمعرض والروابط من config.js
config.js      الروابط والصور وقوائم القصص (الملف الذي تعدّله غالباً)
assets/images/ كل الصور
```

## إضافة صورة أو قصة

1. ضع الصورة في `assets/images/` (يُفضّل WebP أو JPG، وبحجم صغير).
2. افتح `config.js` وأضف سطراً في القائمة المناسبة:

```js
// قصة جديدة في هايلايت يحيى
{ "name": "عنوان القصة", "img": "assets/images/اسم-الصورة.jpg" }

// صورة جديدة في معرض غزل أتولييه
{ "img": "assets/images/اسم-الصورة.jpg", "alt": "وصف قصير" }
```

الترتيب في القائمة هو الترتيب في الصفحة، والأول يظهر من اليمين.

## تغيير رابط

كل الروابط في `links` داخل `config.js`. غيّر الرابط هناك فيتحدّث في كل مكان بالموقع.
مثال: `"whatsapp": "https://wa.me/212782815703"`.

## الصورة الشخصية وصورة الحلقة

استبدل الملفين بنفس الاسم:
- `assets/images/yahya.webp`
- `assets/images/podcast-episode.webp`

## الخط (خط ثمانية)

الموقع جاهز لخط ثمانية: إن وُضعت ملفات الخط في `assets/fonts/` بالأسماء المذكورة في `assets/fonts/README.txt` يُستعمل تلقائياً، وإلا يُستعمل Reem Kufi وIBM Plex Sans Arabic.
الخط يُنزَّل من صفحته الرسمية بعد إدخال بريدك، والترخيص يمنع إعادة توزيع ملفاته، فتحقّق من بند رفعه على الموقع قبل إضافته إلى مستودع عام.

## تغيير فيديو البودكاست

غيّر `podcast.id` في `config.js` (الجزء بعد `youtu.be/`) و`links.podcast`.

## النشر على GitHub Pages

1. ارفع كل محتوى هذا المجلد إلى جذر المستودع (فرع `main`).
2. GitHub ← Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `/ (root)`.
3. الرابط يظهر في نفس الصفحة بعد دقيقة تقريباً.

المسارات كلها نسبية، فيعمل الموقع داخل مسار فرعي مثل `/yahyaeljazari/`.
ولتجربته محلياً افتح `index.html` مباشرة، أو شغّل `python3 -m http.server`.
(تضمين يوتيوب قد لا يعمل عند فتح الملف مباشرة، ويعمل بعد النشر.)
